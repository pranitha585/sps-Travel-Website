# sps-Travel-Website
SPS Travel is a tourism website built using HTML, CSS, and JavaScript. Users can explore destinations like beaches, temples, hill stations, waterfalls, snow regions, and historical places. To view details or book trips, users must login or register. Users can fill a booking form, after which a confirmation message is displayed successfully online.

# Live Demo:
https://pranitha585.github.io/Travel-webiste-sps/

# Features
 - Home page with website introduction
 - Login and Registration system
 - About Us page
 - Contact Us page
 - Destination categories:
   - Beaches
   - Temples
   - Hill Stations
   - Waterfalls
   - Snow Regions
   - Historical Places
 - Detailed information about tourist places
 - Booking form with confirmation message

# Technologies Used
HTML, CSS, JavaScript

How to Run
Download or clone the repository
Open index.html in your browser.
